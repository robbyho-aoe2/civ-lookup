Optimize For

Pick a unit to constantly produce, and this finds the fastest path there — automatically deciding which economy upgrades and extra Town Centers are worth it along the way. Add a stage to plan a transition instead — e.g. Scout Cavalry in Feudal, switching to Knights once Castle hits.

Off (default): a realistic economy — sheep, then wood, then berries/hunt up to pop 20, no Barracks before Feudal, Loom right before advancing. On: skip all of that and build everything the instant it's affordable, prioritizing the target unit above all else. A later stage REPLACES the earlier one's production once its age is reached, it doesn't run alongside it.
